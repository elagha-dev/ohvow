# Honeymoon Intelligence

A curated honeymoon discovery platform. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://elagha-dev.github.io/ohvow/)

## Local Development

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000).

## Stack

- **Next.js 14** — App Router, API Routes
- **TypeScript** — Full type safety
- **Tailwind CSS** — Utility-first styling
- **Vercel** — Zero-config deployment
